## crate new session

```
tmux new -s <session-name>
```

## list all session

```
tmux ls
```

## Attatch or detatch to a session

```
tmux detatch

tmux attatch
# or
tmux a

tmux a -t <session-name>
```

### While on tmux,

press PREFIX-s to list out all the Session
press PREFIX-w to list out all the Windows
